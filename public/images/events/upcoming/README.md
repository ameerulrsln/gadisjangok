# Upcoming event images

Drop posters/photos for upcoming events here.
Edit `src/data/upcomingEvents.js` to change dates, titles and venues.

| File | Used by |
|---|---|
| `upcoming-1.jpg` | 1st upcoming event card |
| `upcoming-2.jpg` | 2nd upcoming event card |
| `upcoming-3.jpg` | 3rd upcoming event card |

Shown at 200px tall, full card width. When the event is over, move its block
into `src/data/pastEvents.js` and its photo into `../past/`.
